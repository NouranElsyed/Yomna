# Yomna & Ahmed — Wedding Invitation

## طريقة التشغيل

1. افتحي التيرمنال جوه الفولدر ده.
2. ثبّتي المكتبات:
   ```
   npm i
   ```
3. شغلي السيرفر المحلي:
   ```
   npm run dev
   ```
4. هيديكي لينك زي `http://localhost:5173` — افتحيه في المتصفح.

## لو عايزة ترفعيها أونلاين (تبعتيها للمدعوين)

```
npm run build
```
هيطلعلك فولدر `dist` جاهز ترفعيه على أي استضافة ستاتيك زي Vercel أو Netlify أو GitHub Pages.
